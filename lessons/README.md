# 受講管理システムを題材としたハンズオン型レッスン

## 概要

- 対象者: LaravelのMVCを理解していて、簡単なCRUDのAPIを実装したことがある人
- 形式: 自習教材（ドキュメント型）
- 技術スタック: Laravel 13 + Inertia.js v3 + React 19 + Fortify
- 位置づけ: 実務現場の前段。「動くコードが書ける」から「現場で通用するコードが書ける」への橋渡し

### 前提知識

- LaravelのMVC構造（ルーティング / コントローラ / モデル / ビュー）を理解している
- Eloquent（ORM）経由での基本的なDB操作ができる
- Dockerとgitの基本操作ができる（`make setup`、ブランチの作成・切り替え）

### 前提としないもの

- 生のSQLを読み書きできること
  - 発行されるSQLやロックの仕組みなど、説明のためにSQLが登場する箇所があります（Lesson 15・16）。ただし読めなくても進められるよう補足を添えているので、SQLそのものを覚える必要はありません
- 実務での設計・運用経験

## 題材概要

受講管理システムを段階的に構築しながら、Laravelの実践的なスキルを習得します。

### エンティティ

- User: 生徒/講師を識別する`role`フィールドを持つ
- Course: 講座
- Attendance: 受講（生徒と講座の中間テーブル）

## 事前準備

> はじめに： まだ環境構築が済んでいない場合は、先に [リポジトリトップの README](../README.md) のセットアップ手順（`make setup`）を完了させてください。

### ブランチの作成

レッスンを進める際は、`main` ブランチで直接作業しないでください。`main` は常にクリーンな状態に保ち、自分の名前でブランチを作成して、その中で作業を進めます。

```bash
# 自分の名前でブランチを作成して切り替える（例: yamada）
git switch -c yamada
```

> 補足: ブランチ名は半角英数字で、自分だと分かる名前にしてください。複数レッスンをまたいでも、この自分用ブランチで作業を続けて構いません。

準備ができたら、[バックエンドのレッスン](./backend/README.md) に進んでください。PostmanとPintの準備は、そちらのページで説明しています。

## トラブルシューティング

### Postman から API にアクセスできない / 応答がない

Docker コンテナが停止している可能性があります。PC 再起動・Docker Desktop の終了・スリープなどの後に起きやすいです。

状態確認

```bash
docker compose ps
```

起動していない場合は `make up` で再起動してください（データは保持されます）。

```bash
make up
```

DB がおかしくなった・初期状態に戻したい場合は以下でリセットできます。

```bash
make fresh
```

> 注意: `make fresh` が実行するのは `DatabaseSeeder` だけです。Lesson 9 以降で作る `CourseSeeder` は呼ばれないため、講座データは 0 件に戻ります。リセット後は以下を実行して講座データを復元してください。
>
> ```bash
> docker compose exec app php artisan db:seed --class=CourseSeeder
> ```
